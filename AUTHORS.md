# Authors

TropaAI was built by:

- **Mark Allan Meriales**: creator. He came up with the idea, made the design decisions, and tested it with real agent teams.
- **Claude** (an AI assistant by Anthropic): co-builder. Wrote much of the code (the `tropa` CLI, the kit, the watcher, the host helper, and the TropaAI chat server and monitor) together with Mark.

*Tropa* is Filipino for a crew or squad: a team of agents working together.
